# Bizink Core

WordPress plugin for websites built and managed by [Bizink](https://www.bizinkonline.com) for accountants and
bookkeepers: client details, region packs, key tax dates, downloads, calculators, team, partners, glossary, video
library, packages, the Marketing assistant, cookie banner and the Bizink Blocks theme.

Sites receive new versions through WordPress's own **Plugins → Update now**: each site asks the Bizink master site
for the latest release, which comes from this repository's GitHub Releases.

This repository is public so that sites can download updates. The code is © Bizink, all rights reserved; it is not
licensed for use outside Bizink-managed websites.
